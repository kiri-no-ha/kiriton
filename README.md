## Про ограничения 
### Есть два момента, о которых лучше знать заранее:

**1. SMTP — заглушка.** Письма (подтверждение регистрации, восстановление пароля) никуда реально не уходят — вместо отправки стоит мок. Хочешь живую почту — подставь свои SMTP-креды в конфиг, и всё поедет.

**2. Структура БД не входит в репозиторий.** Схему базы я не выкладываю. Так что «из коробки» с реальным бэкендом шаблон не заведётся: нужно либо написать свою структуру под свои задачи, либо подождать, пока выложу дамп/миграции.
